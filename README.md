# CRTC 比赛倒计时

Python 3.10+ 与 PySide6（Qt）桌面程序，白底、黄色装饰、红蓝大比分，按 16:9 设计并随屏幕缩放。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

本项目环境已将依赖安装到 `.deps` 时，程序会自动加载该目录；可直接运行 `python main.py` 或双击 `start.bat`。其他电脑请先执行上述安装命令。

打开后有独立的大屏展示窗口和配置控制窗口。建议将配置窗口留在电脑屏幕，在下拉框选择大屏，然后点击“在所选屏幕全屏展示”。同一屏幕也可以使用，按 F2 调出控制面板。

## 操作

- 比分位于独立的“即时比分”区域，修改立即同步到大屏并保存，无需点击保存配置。配置中的“比分上限”可调整为 1～99，默认 3；修改上限后请保存配置，输入范围和大屏点击规则同步生效。降低上限时，超出新上限的现有比分归零。
- 在大屏上左键点击某方比分加一分，右键减一分；达到上限再加归零，0 分再减保持零。窗口缩放或全屏后仍可点击。
- 在比赛信息与显示配置中填写队伍、赛事名称、轮次和各阶段时长，点击“保存并应用配置”。配置保存到程序目录的 config.json，下次启动恢复。
- 点击“从 TXT 导入队伍”，文件每行一个队名，支持 UTF-8（含 BOM）和 GBK。空行会忽略，重复队名去重。导入后在双方队伍下拉框选择，也可以手动填写，再保存配置。导入列表会保存。
- 左上角英文可设置并换行；队名字号可设置为 18～90 像素（按 1920×1080 设计尺寸），过长队名会自动缩小以适应区域。队名下方黄色方框已移除。
- 左上角标题区采用透明黄色环形图案、加粗中文轮次和白色英文黄色底条。英文位置及底条根据中文轮次实际宽度动态调整；过长文字自动缩小，避免重叠。
- 底部滚动信息每行一条，保存后在黄色矩形长条内从右向左逐条循环滚动；消息条贴合窗口底边并铺满整个宽度，非 16:9 窗口同样适用。空行忽略，清空全部消息后显示空黄色长条。
- 滚动字幕采用 36 像素加粗字体（按 1920×1080 设计尺寸），随窗口缩放。
- 控制界面固定使用浅底深字配色，在系统深色模式下仍能清晰显示。采用左右双栏布局，左侧配置比赛信息，右侧控制比分、计时和大屏；所有设置无需滚动即可操作。
- 准备阶段默认 120 秒；正式比赛默认 240 秒。点击相应阶段按钮会重置计时，并等待手动开始。
- 计时控制区可勾选“正式比赛前增加 5 秒倒计时”，保存后，在正式比赛等待状态点击开始或按空格，会先倒数 5 秒，再自动开始完整的比赛时长。默认关闭；暂停、继续不会重新倒数，重置阶段会重新准备倒数。
- 准备阶段申请技术暂停时，点击“技术暂停”，将剩余时间直接覆盖为技术暂停时长（默认 120 秒）。“计时控制”中的“技术暂停后立即开始”默认勾选；取消勾选并保存配置后，覆盖时间会等待手动开始。该选项保存到配置文件。这不是在原有时间上累加，也不自动恢复之前的倒计时；需要再次准备时点击“准备阶段 / 重置”。
- 开始 / 继续和暂停不会改变剩余时间。计时使用单调时钟，避免界面刷新延迟累积造成漂移。
- 准备、技术暂停或正式比赛时间到停在 00:00，大屏显示“时间到”并发出系统提示音；最后 10 秒显示红色。可选的赛前 5 秒倒数结束后会自动进入正式比赛计时。
- 保存时队名、英文、队名字号和滚动信息立即生效；阶段时长在下次重置或切换阶段时生效。保存比赛信息不会覆盖即时比分。
- 大屏快捷键：F11 切换全屏，Esc 退出全屏，F2 显示控制面板。退出全屏时恢复之前的窗口尺寸，并限制在当前屏幕可用区域的 80% 以内，为标题栏留出空间方便拖动。空格在大屏和控制窗口均可开始 / 继续当前阶段计时，重复按下不会暂停；暂停请使用控制面板按钮。编辑文字时空格保留为文字输入。
- 关闭任一主窗口退出程序。运行中的倒计时不会在退出后恢复。

右上角 CRTC 标记使用 `assets/images/CRTCLogo.png`，保持原始比例缩放并保留透明背景。

左上角装饰使用 `assets/images/header-emblem-yellow.png`，由提供的图案去背景并改为黄色；左上角标题区整体缩小至原来的 75%，右上角 Logo 使用原始显示尺寸（设计区域 380×120），保持图片比例。

## 项目结构与维护

项目字体位于 `assets/font/`，程序启动时自动注册，不需要在系统中安装。中文使用 OPPOSans，英文大写强调部分（CRTC 标识及全大写轮次英文）使用 Geometos，其余英文和数字使用 Outfit。中英混排通过字体回退保留中文的 OPPOSans 字形。左上角英文包含小写字母时使用 Outfit。

```text
CRTCCompetition/
├── main.py                 # 程序入口
├── start.bat               # Windows 启动脚本
├── requirements.txt        # Python 依赖
├── assets/font/            # Geometos、Outfit、OPPOSans 字体资源
├── assets/images/          # CRTC Logo 图片资源
├── assets/audio/           # 准备与技术暂停共用的背景音乐
├── config.json             # 用户配置（运行时保存，不纳入版本控制）
├── crtc/
│   ├── app.py              # 创建应用和主窗口
│   ├── runtime.py          # 项目路径、可选 .deps 依赖加载
│   ├── config.py           # 默认配置、兼容校验、JSON 原子存储
│   ├── countdown.py        # 单调时钟计时逻辑
│   ├── teams.py            # TXT 名单解码、校验、去重
│   ├── music.py            # 阶段背景音乐接口与播放状态同步
│   └── ui/
│       ├── control.py      # 比分、阶段、配置和屏幕操作协调
│       ├── control_layout.py # 双栏控件布局与回调绑定
│       ├── audio.py        # Qt 音乐播放器、循环与音量缓入缓出
│       ├── display.py      # 大屏绘制、点击、快捷键和滚动消息
│       ├── header.py       # 左上角赛事标题与动态排版
│       ├── theme.py        # 控制面板配色与样式
│       └── fonts.py        # 字体注册、中英混排与强调样式
├── tests/
│   ├── test_config.py     # 配置兼容、容错和存储测试
│   ├── test_timer.py      # 计时逻辑测试
│   └── test_controls.py   # GUI 操作和配置同步测试
└── timer.py               # 兼容旧 Countdown 导入的薄封装
```

修改设置窗口排版时编辑 `crtc/ui/control_layout.py`；修改颜色编辑 `crtc/ui/theme.py`；修改大屏外观编辑 `crtc/ui/display.py`。比赛操作回调集中在 `crtc/ui/control.py`，配置文件读取和写入集中在 `crtc/config.py`。

字体加载与选择集中在 `crtc/ui/fonts.py`；字体文件使用随项目提供的资源，字体回归检查位于 `tests/test_fonts.py`。

配置、计时与名单解析模块不依赖 Qt。界面层调用这些模块，程序入口只负责启动。`Control(config_path=...)` 支持指定配置路径，测试使用隔离的临时配置，不修改真实比赛信息。根目录 `config.json` 的位置和旧格式保持兼容，新增字段在读取时补充默认值。

配置保存优先使用独立临时文件和原子替换。Windows 暂时锁定文件时会短暂重试；若禁止替换但允许写入，先将旧内容备份到 `config.json.bak`，再写入现有配置文件。此兼容方式不是原子写入，备份可用于恢复。若文件本身也不可写，仍会提示保存失败；请确保项目位于可写目录并关闭占用配置文件的程序。

`.deps/` 为本机可选依赖目录，`.venv/` 为可选虚拟环境，均不属于业务源码。启动方式仍是 `python main.py` 或双击 `start.bat`。

## 背景音乐与扩展接口

已接入 `assets/audio/preparation.mp3`（用户提供的“苏了个一休 - RoboMaster_三分钟准备BGM”）。准备阶段和技术暂停共用同一音源并循环播放，从准备切到技术暂停时不重载、不重新起播；即使技术暂停等待手动开始，已经在播放的准备音乐也保持连续。正式比赛（包括赛前 5 秒倒数）不播放该曲。

“计时控制”中的“启用背景音乐”默认勾选，修改后点击“保存并应用配置”。关闭时音乐淡出，重新开启时按当前计时状态恢复；该设置会保留到下次启动，不影响比赛倒计时或时间到提示音。

默认音量 65%，淡入淡出时长 900 毫秒。开始/继续时淡入；手动暂停、时间到、切换到正式比赛时淡出，再执行暂停/停止；退出时等待淡出完成。快速暂停/继续会从当前音量自然过渡。参数集中于 `crtc/ui/audio.py` 的 `MUSIC_VOLUME` 和 `FADE_DURATION_MS`。播放失败会在控制窗口底部提示。

扩展接口仍在 `crtc/music.py`：播放器实现 `set_phase(phase)`、`play()`、`pause()`、`stop()`，通过 `Control(music_backend=播放器实例)` 注入。应用入口 `crtc/app.py` 默认接入 `QtMusicBackend`，直接创建 `Control()` 则使用静音实现，便于测试。后续可在 `QtMusicBackend.set_phase` 为正式比赛接入独立音源；准备与技术暂停应继续共用源。可选的 `shutdown(callback)` 用于淡出后退出。播放器方法应快速返回，不阻塞 GUI 线程。
